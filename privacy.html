email-digest privacy policy

email-digest is used only by [YOUR NAME], on their own Google accounts.

It reads Gmail messages to write a daily summary that is stored only on the owner's computer. Message content is sent to Anthropic's Claude to produce that summary. If enabled, it may create reply drafts in the owner's Gmail. It never sends, deletes, or otherwise changes messages.

No data is sold, shared with other parties, or used for advertising. Google user data is used only to provide this summary, in line with the Google API Services User Data Policy, including its Limited Use requirements.
